🎓 Trình chiếu Bài tập Toán

Nhập câu hỏi cho 3 dạng bài (Trắc nghiệm · Đúng-Sai · Trả lời ngắn) để tạo bài trình chiếu tương tác — hiển thị sắc nét cho máy chiếu và điện thoại.

🧠📂
Tải file Excel — tự động nhận diện loại câu hỏi
Kéo-thả hoặc bấm để chọn một hoặc nhiều file .xlsx (đọc tất cả các sheet). Hỗ trợ file chuẩn dạng ngân hàng câu hỏi — một bảng gộp chung với cột "Loại" (Trắc nghiệm / Đúng-Sai / Trả lời ngắn) tự phân loại từng dòng — hoặc file chia riêng theo từng phần. Không cần chọn thủ công.
Phần I — Trắc nghiệm 4 đáp án
0 câu
Cột dữ liệu: Nội dung, A, B, C, D, Kí hiệu Đ/A (1-4 hoặc A-D), Lời giải, Link ảnh (Link ảnh không bắt buộc).
Mẹo: mở file Excel, bôi đen toàn bộ vùng dữ liệu (kể cả dòng tiêu đề), Ctrl+C rồi dán vào ô trên.
Phần II — Đúng / Sai (4 ý a,b,c,d)
0 câu
Cột dữ liệu: Nội dung, a, b, c, d, Đáp án a, Đáp án b, Đáp án c, Đáp án d (ghi Đ hoặc S), Lời giải.
Mẹo: mở file Excel, bôi đen toàn bộ vùng dữ liệu (kể cả dòng tiêu đề), Ctrl+C rồi dán vào ô trên.
Phần III — Trả lời ngắn
0 câu
Cột dữ liệu: Nội dung, Đáp án, Lời giải.
Đáp án Phần III là một chuỗi ký tự (số, dấu trừ, dấu phẩy...), ví dụ: -12,5.
Tổng: 0 câu
